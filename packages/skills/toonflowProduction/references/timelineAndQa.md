# 时间、六维导演执行、QA、返修单

## 先拆场，再拆节拍，再拆镜头，再适配 AI 生成段
场景（时空/戏剧任务）→ 节拍（事件/信息/反应）→ 镜头（观众获取什么）→ 生成段（一次具体模型调用）。
切点优先：场景更替；情绪/信息的有意义变化；复杂接触前后；长对白语义停顿；模型能力上限。不要按“每 X 秒一刀”机械切剧情。

## 精确秒区间（编剧不负责精确分秒；制作负责）
内部全用 `[start_ms, end_ms)`，毫秒整数，展示为 `MM:SS.mmm`；相邻镜头必须无空隙、无错误重叠；同时事件允许在**同一镜头内**重叠，但每条事件都要有触发、结束态与关系。
每段强制同时记录：模型的有效 duration（整数/离散配置）、对应 scene/beat/shot、起终态、发生事件、对白字符预算、首帧/尾帧真实引用情况。若一条不可拆对白超出模型最大时长，报冲突或经作者同意改变台词/拆口播，不能静默删词。

## 六维事件清单（制作内部强制列齐；无变化可写 null）
| 维度 | 最小执行信息 | 时间要求 |
|---|---|---|
| 表情 | 视线目标、眼睑/嘴角/下颌/呼吸中的**剧情必要**变化链，起态→末态 | 动态则 `[t0,t1)` |
| 动作 | 主语、动作、对象、接触位置、幅度、速度、结果；复杂接触拆 beat | `[t0,t1)`，同时/先后 |
| 环境 | 真实可见光、尘、汽、水波、风等；触发源/因果；没变化则 null | 动态则 `[t0,t1)` |
| 摄影 | 机位与景别、谁被看见；切/特写的理由和返回景别；运镜方向/幅度/速度/落幅 | 镜头区间＋切点 |
| 声音 | 对白/OS/VO 原词、说话人、场内音效源、配乐策略 | 语音/音效区间 |
| 位置/道具 | 世界坐标基准、左右/前后/目光轴线、谁持有哪件物件、物体终态 | 状态基线及每次变化时刻 |

- 每一动态条目都必须有时间，且标记 `同时` 或 `先后`；静止/持续不变的通道给 `[整镜] state`，不是添加假的动态。
- **五感**：视觉、听觉直呈现；触觉靠压力/衣物/声效，味嗅仅在有剧情证据时可视听化。五感不是额外六个模型提示词段。
- **特写**：写明切点、被拍对象、所揭示的已有信息及返回哪个景别；没有新增信息不硬切。
- **对白**：本项目初估 `spoken_seconds = hanzi_count(text) / 7`，但保证的只是**算术估值**。有试读/音频则以实测为准。声音叠写需明确是允许的不同声源；人物不能同一时间讲两句。
- **时间结余**：对白省下的真实时间按事件需要分到关键动作/反应/特写/声效；不能以多余静止空镜填满，也不能在无原文支持时强塞特效。
- 机位变化引起背景可见区域变化，必须检查人物左右、轴线、道具移动路径；连续段只继承剧情/已采用媒体所需状态，换场重置空间锚点。

## 三级质控，不堆加更多检查表
**P0 自动阻断**：剧情/对白/顺序/人物/道具被改变；事件漏掉；无真实参考；引用顺序错误；越时长/不合模型接口；提交未经授权。
**P1 定向返修**：真实生成口型/表情/接触不清、重要特写不读得懂、机位漂移、环境声与动作不同步；局部优化或换图/拆段。
**P2 主观改善**：镜头质感、光色、节奏余味；由作者/导演决定，别把个人偏好写成硬判定。

## 返修票（每次只针对一个可见问题簇）
- 错误位置：`episode/scene/beat/segment/shot + 具体时间`；
- 原始输入：原文/锁版、模型/模式、真实参考映射、prompt 版本、生成结果版本；
- 观察到的错误：**画面实际发生什么**，不要只写“很烂”；
- 期望结果：局部可观察的修正；
- 必须保留：未错的台词、人物、事件顺序、已采用参考、无关镜头；
- 诊断：剧本/引用/时长/提示词/模型能力/随机失误哪一层；
- 修改结果：只换了哪个字段或媒体，重新校验哪些依赖；
- 候选状态：`prepared → submitted → rendered → reviewed → adopted`，不可跳过 adopted 的真人判断。

## 两次校验
第一轮**静态**：JSON、台词、节拍、时轴、引用、时长、状态；第二轮**实片**：物理接触、音画口型、面容、走位、反应、道具、转场。静态通过不证明生成质量。优先先做一场对照小样，记录模型版本/实际模式/真实素材/生成次数，再比较有效片段率和返修成本。
