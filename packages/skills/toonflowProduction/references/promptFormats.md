# 最终投喂包：不把整个制作方案塞进模型输入

本文件的参考名/时间只是**格式示范**。实际操作必须按现场所选模型官方规范与当前 Toonflow 参数编译。以下出现的 REF 名称如无真实媒体不应发送。

## 包装层（导演审阅；默认不发送模型）
1. **参考输入清单**：逐项 `Ref N / real file or node + adopted version / 首帧|尾帧|角色身份|场景|道具|动作|音色 / 需要继承与不可继承项 / 宿主序号 / 供应商类型序号`。无参考时声明本段 `T2V，不存在媒体引用`。
2. **剧情关联**：剧本 SHA、场/节拍/对白行号、任何经批准的增删/调整。
3. **导演时轴**：每镜 `00:00.000–00:XX.XXX`、同时/先后六维事件、状态起终、对白估时、能力校验。
4. **model_prompt（真正投喂给模型）**：仅一个选择的适配格式，不包含 P0/P1 打分与审稿意见。
5. **验收/返修计划**：本镜可能出错的 1~3 个真正风险，真实试生成后逐条观测。

## Seedance 2.0 `model_prompt` 示意（时间只留在导演时轴）
```text
引用：角色身份参考 {{ref 1}} 仅锁角色甲面部与服装；场景参考 {{ref 2}} 仅锁室内布局。
镜头1：柜台右侧的甲将钱袋推到桌面；袋底碰桌发出闷响。甲同时对左侧乙说：“……”。保持两人的站位和钱袋在桌上的落点。
镜头2：乙先看钱袋，后抬眼看甲，原样答：“……”。镜头不改变桌上钱袋的归属。
镜头3：乙伸手拿起钱袋；回到中景，甲右手在桌边停住，二人形成新的对峙。
```
如果没有实际两张已连接的图，就把清单和 `{{ref N}}` 删除，改真实 T2V 内容。注意 2.0 不承诺响应逐毫秒时间。

## Seedance 2.5 `model_prompt` 示意
```text
参考清单（仅在实际引用已绑定时）：
Ref 1 {{ref 1}} = 图：角色甲身份，只沿用面容与服装；
Ref 2 {{ref 2}} = 图：室内环境，只沿用布局和光色。
0–4 秒｜中景：甲将钱袋推上桌，与落桌闷响同步说出原文第一句，乙在画面左侧看着钱袋。
4–7 秒｜乙中近景：先落眼于钱袋，后抬眼答出原文第二句；甲在背景不说话。
7–10 秒｜桌面手部特写：乙拿起钱袋；切回两人中景，甲的手停住，完成状态变化。
```
这里的整数秒是模型可读节奏，不是精确帧级时间保证。

## H3 Base T2VA 示例（无图、无视频、无音频输入）
```text
integrated_multimodal_description: [Shot 1] 室内柜台中景，甲在右、乙在左。甲右手缓慢把钱袋推向乙，袋底触桌；甲(S1)用中文说：<d>[Chinese] ……</d>。[Shot 2] At 00:04.000 乙先看钱袋再抬眼，乙(S2)说：<d>[Chinese] ……</d>。[Shot 3] At 00:07.000 手部特写，乙伸手拿走钱袋，回到两人中景，甲的手停在桌边，双方状态保持至结束。
overall_soundscape: 室内轻微环境底噪，钱袋触桌的短促闷响，衣袖和钱袋摩擦声。
non_diegetic_music: N/A.
```
上述“……”只是说明形式，不能充当真实台词；必须从 `line_id` 原样替换。

## H3 I2VA 首行格式
当且仅当确有可用真实首帧，必须依 H3 当前官方 Base 指南把具体图片对齐指令放在 `model_prompt` 第一行；**不能在前面加独立的中文素材清单破坏对齐行**。人类清单在外部包装层，之后才是精确的 H3 字段（与上传 H3 适配附件不同，可验证的官方结构优先）。

## H3 Ref2VA 字段顺序
```text
subject_definitions: <Subject 1> 由实际 <Picture 1> 提供身份与服装；<Picture 2> 仅作场景布局参考，不复制其中人物。
summary: 角色甲将钱袋推至乙面前；乙看后应答并收取。
retention_analysis: <Picture 1> 角色身份 fully_preserved；<Picture 2> 背景布局参考，角色不迁移。
detailed_description: [Shot 1] ... [Shot 2] At 00:04.000 ... [Shot 3] At 00:07.000 ...
overall_soundscape: ...
non_diegetic_music: N/A.
```
H3 Ref2VA 不使用 `{{ref N}}` 替代 `<Picture N>`，由投喂包映射表给出真实一一对应。

## 始终禁止
- 直接把剧情审计/模型选择论证/返修票塞入实际 `prompt`；
- 随意为每个人添一段情绪词或无意义微表情链；
- 对 H3 Base 首行对齐、Seedance 参考类型或用户要求的“清单先行”采取互相冲突的单一格式；
- 复述参考图所有像素，忽略本段真正发生的动作；
- 假装未绑定引用能生成，或用故事计划里的 `asset_id` 冒充实际 Toonflow 媒体 ID。
