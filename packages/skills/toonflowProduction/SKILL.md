# Toonflow 导演与视频制作

**唯一入口：已确认剧本 + `drama-to-toonflow/1.0.0` 交接包。** 本 Skill 继承创作决定，不再运行桥段配方、改编和另一套剧情导演重写。用户只要求分镜/提示词就停在文本，不擅自生成视频。

## 唯一信息优先级
`用户本轮锁定范围 > 定稿剧本原文及哈希 > 交接包 hard 锁 > 已批准画布实际成果 > 交接包 soft 导演建议 > 模型适配建议`。
交接包与原文冲突 → **停在冲突场**列差异；不自行改对白、加剧情或改变人物认知。未锁包可以做草稿，不得标记可执行。

## 五步制作法
1. **核实并只读现场**：读取当前剧本/交接包、目标 Toonflow 画布已采用资产及版本、节点真实参考、模型/供应商/模式/实际可选时长与声音能力。缺项明确标记；不能为了套模板锁死 Seedance，也不能把“模型官网最大值”视为当前账号/供应商支持。
2. **导演编排**：先按场（时空和戏剧任务）→节拍（关键动作/信息/反应）→镜头（观看什么、为何切）→**生成段**（单次模型调用）。场景边界默认不塞进同段；允许真实能力支持时在同一生成段放多个镜头，但先审动作、对白、换角和参考复杂度。保留 `scene_id/beat_id/line_id` 链；影片总时长是结果，不反向删除必需节拍。
3. **建立时间和六维执行卡**：每个镜头及每个动态事件在内部有 `MM:SS.mmm` 起止时间；注明 `同时/先后`。覆盖 **表情、动作、环境变化、摄影（景别/特写/切镜/运镜）、声音、位置与道具状态** 六类。某类确实无变化时明写 `无变化/不适用`，不强造飘尘或无意义眼神。每个动作写主体、对象、幅度/速度、结束态；高风险接触拆 beat。时间计算见 `references/timelineAndQa.md`。
4. **先映射真实素材，再编译执行提示词**：先展示参考清单 `本段每项真实输入 → 来源节点/路径/采用版本 → 首帧/尾帧/角色/场景/道具/动作/音色及使用范围 → 宿主顺序 → 供应商素材类型序号`，再在允许的模型语法中引用。不能拿示例 ID 当素材、不能越过清单直接写 `{{ref N}}`；执行前再次核验排序。按唯一选中的适配器输出 **模型可直接发送的 prompt**，审阅/时间轴/修订意见作为伴随文件，不整页复制进模型 prompt。见 `references/modelRouting.md`。
5. **预检→授权→生成→验收→采用**：先核对白字/事件/起终态/时长/声音/参考链，用户批准本次生成范围后再实际提交。调用状态成功≠媒体成功≠用户采用；通过播放回看核查口型、接触、身份、剪辑、环境、对白及收尾。返修只动受影响镜头及下游依赖，不无限循环加词。

## 必须遵守的控制
- **剧本保真**：对白逐字，事件顺序与结局不变。细化手部接触与表情必须有剧情依据；不能为了“画面饱满”发明新的事件。
- **时间与并行**：每镜 `[t0,t1)`；前段末态与后段初态匹配。对白初估采用交接包中的项目语速（若设置为 7 汉字/秒则据此估算），同一人不可并行说两句；对白压缩出的空间可用真实动作、反应、声效、特写，不可自动塞静止空镜。
- **镜头密度**：明确“这次切镜给观众新信息是什么”，一个镜头优先一个主变化。信息过载先拆生成段、静态运镜或简化高风险交互，不复制长篇重复的负面约束。
- **引用清单先行**：用户可读投喂包必须“清单在前、正文引用在后”。若模型强制首行格式（H3 I2VA/FL2VA），真实映射放在**独立执行清单**而非破坏模型原生首行；H3 Ref2VA 的 `subject_definitions` 放在 model_prompt 起首。双重清单由工具映射一致性校验。
- **模型不是一个提示词方言**：Seedance 2.0 内部有精确时间，送模型的多镜正文**以镜号与顺序为主**；Seedance 2.5 可用连续的整数秒时间块；H3 按官方三字段或六字段及镜头标签输出。用户要求的毫秒级时序始终保存在**制作时轴**，不谎称某模型每毫秒都服从。
- **六维不是六套强制啰嗦叙述**：制作执行卡六维齐全；最终模型 prompt 只编译与实际场景相关的有动作条目及必要状态锁。模型语法和结构不得被“优化器”二次重写。

## Toonflow 使用边界
仅使用当前实际暴露的画布工具和实时 schema；用 `getCanvas` / `findCanvasNodes` / `getCanvasNodes` / `getCanvasEdges` / `getNodeTools` 核实，再 `addNode` / `nodeTools` / `connectNodes` 等执行，**不直接篡改画布 JSON**；若工具不可用仅交文本投喂包。详细协议与异常见 `references/toonflowCanvas.md`。重排参考、替换媒体或改模型都需重编译当前段，并保留已采用媒体。

## 交付
每段同时交：1) `导演时轴（审阅）`，2) `素材清单与供应商引用映射`，3) `本次唯一 model_prompt`，4) `QA/风险及实际状态`。视频阶段另记生成任务、产出/采用状态与返修票。关键示例见 `references/promptFormats.md`，预检见 `references/timelineAndQa.md`。
