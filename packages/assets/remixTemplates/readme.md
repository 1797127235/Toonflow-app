# 一键生同款模板资料

从 infinite-canvas 的 `web/public/templates/templates.json` 及同目录媒体提取，共 10 套工作流、70 个媒体文件和 10 张封面。保留原提示词、配置与历史示例，去掉画布坐标及节点 UI 数据，将节点引用转换成模板内的稳定 ID。

当前为 **已提取资料（extracted）**。首页提供卡片与创作弹窗，收集用户素材及说明后，先把素材、提示词正文、生成步骤和参考连线写入新项目画布，再交给创作助手核对模型及生成授权。画布初始化不依赖对话模型；尚未提供独立的确定性步骤执行器，未验证所有模板的新素材生成效果。原项目未作修改。

## 文件

- `index.json`：栏目索引、封面、可选视频预览、输入数量与生成步骤数量。路径相对此目录。
- 每个模板目录的 `template.json`：输入、文本、步骤、依赖、原参数和适配说明。媒体路径相对此模板目录。
- `cover.webp`：原栏目封面。
- `mediaN.*`：原输入样例、过程图与历史结果；具体用途由 JSON 的 `inputs`、`steps.example` 和 `previewVideo` 指明。
- `sourceLicense.txt`：保留来源仓库 MIT 许可证。样例媒体未单独核实人物、商品及再分发授权，正式展示前需确认或更换。

## 数据含义

| 字段 | 用途 |
| --- | --- |
| `inputs` | 工作流外部媒体输入；`example` 仅是原输入样例，不能自动代替用户素材 |
| `texts` | 场景、姿势、口播或策划原文；需要按模板判断哪些开放编辑，哪些固定 |
| `steps` | 图片、视频、音频或文本生成操作，包含配置节点与直接生成的媒体节点 |
| `promptTemplate` | 原执行提示词；`@[node:...]` 已改为 `{{inputN}}`、`{{textN}}`、`{{stepN}}` |
| `references` | 原步骤实际引用顺序及类型，`source` 指向输入、文本或上游步骤；`label` 是资料标识，不是 Toonflow 或供应商原生语法 |
| `connectedButNotReferenced` | 原画布已连线、却被 composer 的显式引用机制遗漏的输入；不能当作已投喂 |
| `dependsOn` | 本步骤需要的上游生成结果；执行顺序以依赖为准，不以数组或标题序号为准 |
| `settings` | 原节点设置；字符串布尔值、尺寸、时长和分辨率均未冒充 Toonflow 的执行协议 |
| `originalModel` | 原渠道与模型标识，只用于追溯，不能直接作为 Toonflow 模型 ID |
| `steps.example` | 该步骤的历史媒体产物，只供展示，不是本次任务已完成的结果 |
| `outputs` | 没有被其他提取步骤引用的终点；可能是多个独立成果，也可能是互斥分支，不能默认全部执行 |
| `adaptationNotes` | 按模板记录的引用遗漏、模型需求、文案占位及流程差异 |

没有显式 `{{...}}` 的旧提示词，也可能通过 `references` 引用媒体和追加文本。接入时必须保留这些关联，不能只替换字符串就提交生成。原始节点 ID 留在 `sourceNodeId` 等字段，便于回查。

## 接入一键生同款时

先固定模板的用户输入和选中分支，将输入样例、历史过程图和历史成品严格分开。随后按依赖执行步骤，将本次真实输出提供给下游；文本生成结果同样必须重新取得，不能使用旧示例中的产品描述。

模型与参数从 Toonflow 当前可用能力查询和映射，核对图片编辑、多图参考、视频参考、时长及原生音频。素材顺序需要编译成目标工具实际支持的引用方式，不把原节点 ID 或资料标签直接发给模型。修复 `adaptationNotes` 指出的提示词遗漏后，才适合接入用户素材并验证生成效果。

模板原始资料不包含 Toonflow 画布 JSON；首页按本次输入生成新画布及节点文件，没有新增执行器。首页弹窗不直接提交付费生成；项目内创作助手仍需核对模型及生成授权。首个实际生成验证案例可选流程短、仅有一个用户输入的 `apparelShowcaseVideo`。
